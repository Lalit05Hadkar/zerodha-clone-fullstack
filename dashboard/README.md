# Zerodha Kite Dashboard - Trading Terminal

Institutional and retail web trading terminal replicating the core Zerodha Kite experience.

## Features
- **Live Stock Watchlist**: Searchable equities with simulated real-time price fluctuations and percentage gainers/losers.
- **Order Execution**: Buy and Sell trade windows with margin requirement calculation (`Price × Quantity`) and instant balance synchronization.
- **Holdings Analytics**: Total Investment, Current Valuation, Net P&L metrics with interactive **Chart.js** asset allocation.
- **Positions**: Intraday derivatives and equities position tracking.
- **Funds Management**: Add funds with preset instant UPI values (`+₹1,000`, `+₹5,000`, `+₹10,000`) and safe fund withdrawal verification.
- **Apps Marketplace**: Ecosystem hub connecting Smallcase, Sensibull, Streak, Ditto, and Zerodha Fund House.

## Development
```bash
npm install
npm start
```
Runs at `http://localhost:3001`.
