# Zerodha Frontend - Web Platform & Onboarding

Client-facing landing portal and investor onboarding experience for the Zerodha Full-Stack ecosystem.

## Features
- **Landing Ecosystem**: High-converting Home, About, Pricing, Products, and Support experiences.
- **Support Desk & Knowledge Base**: Searchable FAQ portals and ticket routing.
- **3-Step Client Registration**: Mobile number validation, SMS OTP authentication simulation, and auto-generated Client ID leading into the Kite trading terminal.

## Development
```bash
npm install
npm start
```
Runs at `http://localhost:3000`.
